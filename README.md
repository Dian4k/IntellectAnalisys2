Описание fnlwgt — final weight, итоговый вес

Веса в файлах CPS — Current Population Survey, «Текущее обследование населения» — корректируются в соответствии с независимыми оценками численности гражданского неинституционализированного населения США.

Эти оценки ежемесячно подготавливаются Population Division Бюро переписи населения США.

Используются три набора контрольных показателей:

Единая оценка численности населения в возрасте 16 лет и старше для каждого штата.
Контрольные показатели латиноамериканского происхождения в зависимости от возраста и пола.
Контрольные показатели по расе, возрасту и полу.

В программе взвешивания используются все три набора контрольных значений. Процесс итеративной корректировки — «raking» — выполняется шесть раз, чтобы в итоге результаты соответствовали всем используемым контрольным показателям.

Термин estimate («оценка») означает оценки общей численности населения, полученные на основе CPS путём создания взвешенных итоговых значений для заданных социально-экономических характеристик населения.

Люди с похожими демографическими характеристиками должны иметь похожие веса.

Однако необходимо учитывать важное ограничение: выборка CPS фактически состоит из 51 отдельной выборки по штатам, каждая из которых имеет собственную вероятность отбора. Поэтому утверждение о сходстве весов применимо только в пределах одного штата.
